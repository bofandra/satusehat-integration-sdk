# Code of Conduct

Contributors are expected to communicate professionally, focus discussion on the technical work, respect differing experience levels and perspectives, and avoid harassment, discrimination, threats, or disclosure of another person's private information.

Security issues, credentials, access tokens, patient identifiers, and clinical data must not be posted in public issues or pull requests. Repository maintainers may edit, lock, or remove content that creates a security, privacy, or safety risk.

Project owners should define an official private reporting/contact channel before public launch.
