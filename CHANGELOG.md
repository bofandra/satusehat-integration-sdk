# Changelog

## 0.1.0 - 2026-08-12

Initial official production-ready reference SDK release:

- six SDK languages;
- OAuth2 client credentials;
- FHIR client;
- SQLite persistent queue;
- queue worker;
- idempotency keys for duplicate-safe enqueue from facility outbox publishers;
- queue stats, dead-letter listing, and requeue admin primitives;
- stale `PROCESSING` lease recovery;
- retry/error classification;
- SATUSEHAT-aligned PATCH `Content-Type: application/json`;
- common schema and documentation;
- GitHub, package registry, security, sandbox contract, and release evidence workflow definitions.
